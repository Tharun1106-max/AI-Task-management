# TaskPilot Deployment Configurations 🚀

This directory contains cloud deployment manifests and infrastructure definitions for hosting TaskPilot:

- `render.yaml`: Render Blueprint infrastructure-as-code specification for backend and frontend services.
- `railway.json`: Railway deployment manifest with healthchecks and start command overrides.
- `../docker-compose.yml`: Root multi-container orchestration for staging and local development.
- `../docs/DEPLOYMENT.md`: Comprehensive step-by-step deployment guide for Render, Railway, Atlas, Vercel, and Docker.
